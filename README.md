# PROJECT : ECLIPSE

Cybersecurity / Cloud Security portfolio for Samanyu Dhangar.

## Run locally

Open `index.html` in a browser.

For a local server, from this folder run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository named `SamanyuDhangar.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. Your portfolio should be available at:
   `https://SamanyuDhangar.github.io/`

## Before publishing

Replace:
- The LinkedIn URL in `index.html`.
- Placeholder project links.
- Project descriptions with your actual projects.
- Any credential details that need exact verification links.
- Optional profile image/assets.

Do not put passwords, API keys, tokens, private IPs, or other secrets in this repository.
