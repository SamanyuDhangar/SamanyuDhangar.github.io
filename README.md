# PROJECT : ECLIPSE

Cybersecurity / Cloud Security / AI Security portfolio for **Samanyu Dhangar**.

Single-page, framework-free static site (works on GitHub Pages).

## Flow
1. Dark, shadowy loader (fog, scanlines, boot log, progress bar).
2. Landing: name, role, short intro + **EXPLORE** / **CONNECT**.
3. Both buttons pull you down a black-hole / abyss transition.
   - **EXPLORE** → About, Mission, Skills, Journey, Projects, Credentials, Lab.
   - **CONNECT** → contact details (GitHub, LinkedIn).

## Files
`index.html` (content) · `style.css` (design) · `script.js` (loader, abyss transition, tabs, lab tools)

Run locally: open `index.html`, or `python3 -m http.server 8000`.
